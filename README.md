# 科兹中心目标价值计算器

一个原生 Windows C++ GUI 程序，用于在 GTA Online 科兹中心豪劫中，根据侦察到的目标实际价值和 100% 背包容量，计算最高价值拿取方案。

## 功能

- 内置 `科兹中心目标价值.xlsx` 中的全部目标名称、地点、参考价值区间和背包占用。
- 每个不同名称的物品在一次任务中最多出现一次；普通区域和 202 展览室中的同名选项互斥。
- 物品加入清单后，其全部同名地点选项会从搜索列表中隐藏；移除或清空后自动恢复。
- 目标下拉框支持快速输入筛选：可输入目标名称、地点或容量文字中的连续关键字快速定位。
- 使用 0/1 背包动态规划精确求解，不采用简单的价值/容量贪心排序。
- 可选择 1–4 名玩家；2–4 人时自动启用 202 展览室目标。
- 多人模式把每个人视为彼此独立的 100% 背包；容量不会合并，每件物品只能完整放入一名玩家的背包，不能跨玩家拆分。
- 只有每名玩家各自都恰好装满 100% 时，组合才会被视为有效方案。
- 如果当前目标无法让全员满包，会明确提示并显示最接近的均衡分配供参考。
- 界面支持简体中文与繁體中文即时切换，并使用放大的中文字体提高可读性。
- 每条侦察目标可标记为“买家指定”；拿齐全部指定物品后，简单难度每位玩家获得 `$50,000`，困难难度每位玩家获得 `$100,000` 的买家请求奖励。
- 优化器会比较放弃奖励与拿齐指定物品两类方案，按包含所有玩家独立买家请求奖励后的确定团队收益选择最优解。
- 精英挑战奖励与买家指定物品奖励相互独立：简单难度为每人 `$50,000`，困难难度为每人 `$100,000`。
- 拿齐全部买家指定物品时，额外显示精英挑战参考方案。由于还需满足其他挑战条件，潜在精英奖励不会计入确定收益；多人参考值按每位玩家均获得奖励计算。
- 多人任务中，所有拿取目标的总价值由全体玩家平分；背包分配仅表示各玩家携带哪些物品，不代表该玩家独占其携带价值。
- 计算结果不包含主要目标和脱身载具报酬：队长需另加主要目标价值及仅由队长获得的脱身载具报酬，队员需另加 `$100,000`（简单）或 `$200,000`（困难）。
- 单人仍可录入侦察到的 202 展览室物品；它们会被排除。若其中包含买家指定物品，程序会明确判定买家指定奖励与精英挑战参考均无法完成。
- 输入值超出参考区间时会提示，但允许以侦察到的实际值继续计算。

## 构建

需要 Windows、CMake 和 Visual Studio C++ 工具链。

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

生成的程序位于 `build/Release/KortzCenterCalculator.exe`。

## 使用

1. 在右上角选择本次游玩的玩家人数。
2. 从下拉框选择侦察到的目标和地点；也可以直接输入名称或地点关键字实时筛选。
3. 输入侦察显示的实际价值；如果它是买家指定物品，同时勾选相应标记后加入清单。
4. 选择简单或困难难度，以确定每人的买家请求奖励和潜在精英挑战奖励。
5. 点击“计算最优方案”；清单变化时程序也会自动刷新结果。

每名玩家的背包容量均为 100%，每件目标视为不可拆分。单人模式在一个背包内求最高价值；2–4 人模式同时求所有玩家的分配方案，并要求每个人都恰好达到 100%。
